# Getting started

Four chapters take you from an empty folder to a running bot with a live panel in it. The first two chapters set up your project, while the last two build your about panel and wire it into a working bot. Because every chapter ends with something you can run, you'll always know your setup works before moving on.

1. [Installation](installation.md) — Set up a fresh TypeScript project ready for building panels.
2. [Project setup](project-setup.md) — Add a source folder, an entry point, and a run script.
3. [Your first panel](your-first-panel.md) — Build a stateless about panel end to end.
4. [Hosting and commands](hosting-and-commands.md) — Run your bot with `createBot` and open the panel with a slash command.
